# WoW SoD


## Config

Place the file ``` Config.wtf ``` (graphics settings) in the directory:

``` C:\Program Files (x86)\World of Warcraft\_classic_era_\WTF ```

And then, place in the ``` Account\<AccountID>#1 ``` directory the files:

- ``` bindings-cache.wtf ``` (keybindings)
- ``` config-cache.wtf ``` (camera settings)

N.B: ``` World of Warcraft\<GameVersion>\WTF\Account\<AccountID> ```


## Addons

Addons:
- Details! Damage Meter
- BetterVendorPrice
- VendorPrice
- GearQuipper
- Questie

To be unzipped and placed in:

```
C:\Program Files (x86)\World of Warcraft\_classic_era_\Interface\AddOns
```
